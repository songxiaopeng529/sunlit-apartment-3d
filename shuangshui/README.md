# 双水村 · 《平凡的世界》3D 文学场景复原

**在线体验**：<https://songxiaopeng529.github.io/sunlit-apartment-3d/shuangshui/>

- 陕北黄土高原中的双水村：东拉河与哭咽河在庙坪前交汇，河西田家圪崂、河东金家湾
